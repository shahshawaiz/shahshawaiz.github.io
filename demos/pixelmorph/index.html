Style tips

An on-device language model suggests hairstyles and glasses for your face shape. Only the shape name and ratios are used, never the photo.

Face swap: server version only

The full PixelMorph app also does single- and multi-person face swap with InsightFace (ONNX Runtime) behind a FastAPI backend. It isn't part of this web demo, because:

  • the swap model is about 550 MB, too large to download in a browser tab;
  • its weights are licensed for non-commercial research only;
  • swapping faces involves other people's likeness, which needs consent and safeguards that a public demo can't enforce.

See the repository README to run the full app locally with Docker.
